Middleware

// middleware.ts
export async function middleware(request: NextRequest) {
  const supabase = createServerClient(...)
  const { data: { session } } = await supabase.auth.getSession()

  if (!session && request.nextUrl.pathname.startsWith('/dashboard')) {
    return NextResponse.redirect(new URL('/login', request.url))
  }
}

Rutas protegidas

  • /dashboard/* - Requiere sesión
  • /api/* - Requiere sesión (retorna 401)
  • /login - Pública

10. Flujos Principales

Flujo: Crear Cuadratura

1. Usuario navega a /dashboard/cuadraturas/nuevo 2. Selecciona fecha, turno, responsable 3. Ingresa ventas (combustible + tienda) 4. Agrega depósitos (array JSONB) 5. Agrega vouchers (array JSONB) 6. Ingresa gastos (objeto JSONB) 7. Sistema calcula automáticamente: - total_no_efectivo = tarjetas + vouchers + gastos - efectivo_esperado = ventas - total_no_efectivo - diferencia = efectivo_real - efectivo_esperado 8. INSERT en tabla 'turnos' 9. Redirect a historial con toast de éxito

Flujo: Importar Excel

1. Usuario sube archivo .xlsx 2. Sistema detecta modo (cuadraturas vs ausencias) por nombres de hojas 3. Auto-detecta mes/año del nombre del archivo 4. Para cuadraturas: a. Lee hojas 01-31 (días del mes) b. Extrae turnos por columnas (A=Mañana, B=Tarde, C=Noche) c. Lee "RESUMEN DE GASTOS" para gastos adicionales d. Busca match de nombres en BD (exacto → parcial → palabra) 5. Muestra preview con validación (rojo = sin match) 6. Usuario corrige manualmente nombres no encontrados 7. INSERT batch en tabla correspondiente

Flujo: Enviar Liquidaciones

1. Usuario sube PDF consolidado (1 página por persona) 2. pdf-lib separa páginas individuales 3. pdfjs-dist extrae texto de cada página 4. Regex detecta RUT: /\d{1,2}\.\d{3}\.\d{3}-[0-9kK]/ 5. Match RUT con tabla 'personal' 6. Preview con asignaciones (usuario puede corregir) 7. Para cada empleado: a. Sube PDF individual a Storage (nominas/{id}/{año}_{mes}.pdf) b. INSERT en tabla 'liquidaciones' c. POST /api/enviar-liquidacion (Nodemailer) 8. UI actualiza estado a "ENVIADO"

12. Seguridad

Medidas implementadas

  • Middleware de Auth: Protege rutas /dashboard/* y /api/*
  • Row Level Security (RLS): En Supabase para tablas sensibles
  • Validación de entrada: Sanitización de datos en formularios
  • HTTPS: Forzado por Vercel
  • Cookies HttpOnly: Sesiones manejadas por Supabase

Validaciones de API

// /api/enviar-liquidacion
if (!to || !subject || !pdfBase64) {
  return NextResponse.json({ error: 'Faltan campos' }, { status: 400 })
}

// Validación de email
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
if (!emailRegex.test(to)) {
  return NextResponse.json({ error: 'Email inválido' }, { status: 400 })
}
