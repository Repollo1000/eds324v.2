🎯 Puntos de Decisión

¿Cuándo invertir en infraestructura?

  • Hasta 3 clientes: Plan gratuito es suficiente. No gastar.
  • Cliente 4: Evaluar si el free tier aguanta. Probablemente sí.
  • Cliente 5+: Pasar a planes pagados (~$70.000/mes)
  • Cliente 10+: Considerar sueldo fijo para ti
REGLA DE ORO
Costos de infra < 10% de ingresos
Con 5 clientes ($2.5M) → máximo $250.000 en costos de infra

IVA en Servicios de Software (Ley 21.420)

Desde 2023, los servicios de software están AFECTOS a IVA (19%).

  • Debes cobrar IVA en cada factura a tus clientes
  • Factura de $500.000 + IVA = $595.000 total
  • Los $95.000 de IVA los pagas al SII mensualmente
  • Puedes descontar el IVA de tus compras (crédito fiscal)

💼 Tu Sueldo como Dueño

Opciones para pagarte

Opción Cómo funciona Impuestos Cotizaciones Recomendado
Sueldo empresarial Te pagas como empleado Imp. Único 2ª Cat. AFP + Salud (~20%) ✓ Sí
Retiro utilidades Sacas de las ganancias Global Complementario No tiene Complemento
Honorarios Boleta a ti mismo Retención 15.25% Obligatorias ✗ No

¿Por qué sueldo empresarial?

  • Es gasto para la empresa → reduce utilidades → menos impuesto a la renta
  • Acumulas AFP y salud → pensión, FONASA/Isapre, licencias médicas
  • Demuestras ingresos formales → créditos, arriendo, hipotecario
  • El SII lo acepta → si trabajas efectivamente en la empresa
